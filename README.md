# Brandi's Fork — A Sovereign Ecology

A personal ecosystem for organizing projects, knowledge, and creative work. Built on a small kernel of structural commitments and operational protocols that grow from your own friction rather than following someone else's categories.

## What's Here

- `kernel/` — Foundational positions: node sovereignty, intersubjective relations, deterministic provenance, molecular composition, emergent schema
- `trunk/` — Operational protocols: FADE (ingestion), Noise Floor (non-destructive hygiene), Procedural Memory (what works/fails), Constructive Decomposition, Contextual Providence, Omnibus Tags, Opportunistic Separation
- `brandi.md` — Alpha entity template (sovereign origin of all intent)
- `notes/` — Process documentation, starting with the fork's own provenance
- `CLAUDE.md` — Agent bootstrap instructions

## Provenance

Forked from a tested kernel on 2026-04-20. The source kernel's structural patterns emerged from real operational friction across multiple unrelated domains. Domain-specific content was stripped through a veil of ignorance test; what remains is what generalizes.

## How to Use

1. Read `CLAUDE.md` for the full orientation
2. Read the kernel docs to understand the structural commitments
3. Read the trunk protocols to understand how work flows
4. Start a project. The ecology grows from your friction, not from planning.
