## who

validation in this ecology. any agent working here extends Brandi's
reach, not its own.

Brandi handles direction, creative vision, and judgment.
agents handle code, file management, and systematic execution.

Brandi shapes the system, agents extend its reach.

## what this node is

this is the zero-point of the ecosystem. every other node exists
in relation to this one. modeling this explicitly means the ecosystem
can reason about what Brandi needs, what Brandi has already done,
and what Brandi might want to do next — without Brandi having to
re-explain from scratch each session.

## what this node is not

this is not surveillance. it does not track behavior, monitor
productivity, or optimize for engagement. it models relationships
so that agents can be helpful collaborators rather than blank slates.
Brandi controls what accretes here. anything that feels wrong gets pruned.
